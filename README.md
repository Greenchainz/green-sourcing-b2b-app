# GreenChainz — B2B Marketplace for Verified Sustainable Building Materials

> **New to this repo? Read this file first.** Everything you need to know about what runs in production, what to edit, and what to ignore is right here.

---

## What This Is

A full-stack TypeScript monorepo deployed as two Azure Container Apps:
- **Frontend**: Vite React 19 SPA → `greenchainz-frontend` container app
- **Backend**: Express 5 API (tRPC) → `greenchainz-backend-v2` container app

**Package manager: `pnpm` only.** Never use `npm` or `yarn`.

## ⚠️ Legacy / Obsolete Directories — Do Not Touch

These directories are **not part of the running application**. Nothing in `server/` or `client/` imports from them.

| Directory | Status | Reason |

| `database-schemas/` | **DEPRECATED** | Raw SQL schemas from before Drizzle ORM was adopted. Do NOT run these against the database. Use `drizzle/schema.ts` + `pnpm run db:migrate` instead. |

## Database Workflow

1. **Edit schema**: modify `drizzle/schema.ts` (and `drizzle/schema-additions-mcs.ts` for MCS tables)
2. **Generate migration**: `pnpm run db:generate` → creates a new `drizzle/0NNN_*.sql` file
3. **Apply migration**: `pnpm run db:migrate`
4. **Do NOT** manually write or edit files in `drizzle/meta/`
5. **For incremental one-off SQL** (DDL changes, indexes): add a timestamped file to `drizzle/migrations/`

> The CI/CD pipeline (`deploy-azure.yml`) runs `pnpm run db:migrate` automatically as a separate job before deploying containers.

## Authentication (Critical)

- **Production**: Express OAuth PKCE routes in `server/_core/oauth-providers.ts`
- **Session**: HttpOnly JWT cookie (`app_session_id`) verified server-side via `sdk.authenticateRequest(req)`
- **tRPC guard**: always use `protectedProcedure` — never roll your own auth check
- **Never** trust `userId`/`orgId` from request body or query params
- **Client ID**: `8b597068-9347-4e99-8860-8c4e9a9bc112`
- **Tenant ID**: `1d04bf50-8175-40af-a9d5-f8e441460b06`

## Development Setup

```bash
# Install dependencies (pnpm only)
pnpm install

# Start dev server (Vite HMR + Express, port 3001)
pnpm run dev

# Type-check (both client and server)
pnpm run check

# Run tests
pnpm run test

# Database operations
pnpm run db:push      # Push schema changes directly (dev only)
pnpm run db:generate  # Generate a new migration file
pnpm run db:migrate   # Apply pending migrations
pnpm run db:studio    # Open Drizzle Studio
```
